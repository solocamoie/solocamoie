## just solocamoie, writing code 👋

I write Rust and C for a living and for fun, which probably says something about me I haven't fully figured out yet. Most of what I build lives in the terminal or below the application layer, where a cache miss actually matters and the allocator is a real character in the story. Lately I've been drawn into WebAssembly as a compile target, partly for the performance story and partly because it feels like an old idea finally finding its shape.

- 🔭 A WebAssembly runtime in Rust that boots faster than the shell it replaces.
- learning C the slow way
- usually building small tools nobody asked for
